# Quickstart: 003-event-indexing

**Branch**: `003-event-indexing` | **Date**: 2026-09-13

## 配置（env-only，沿用 001/002 约定）

```sh
# 必需：日志扫描起点（无默认值，创世 0 合法）
TXHARBOR_LOG_START_HEIGHT=0
# 必需：白名单（逗号分隔；空白/空集合拒绝启动，绝不全链查询）
TXHARBOR_LOG_CONTRACTS=0x1111111111111111111111111111111111111111,0x2222222222222222222222222222222222222222
# 可选：每批最大块数（默认 500；生产值由 provider 附录复核）
TXHARBOR_LOG_BATCH_BLOCKS=500
# 复用：TXHARBOR_INDEX_RPC_TIMEOUT / TXHARBOR_INDEX_POLL_INTERVAL /
#       TXHARBOR_INDEX_RETRY_INITIAL / TXHARBOR_INDEX_RETRY_MAX
```

白名单大小写/顺序/重复差异不视为配置变化；新增或删除地址、修改起点必须判为变化（比较对象是行内 `start_block`，不是 `next_block`）。
