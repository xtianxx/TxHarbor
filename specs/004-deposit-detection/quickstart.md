# Quickstart: 004-deposit-detection

**Branch**: `004-deposit-detection` | **Date**: 2026-09-13

## 配置（env-only，沿用 001/002/003 约定）

```sh
# 必需：充值全局起点（无默认值，创世 0 合法）
TXHARBOR_DEPOSIT_START_HEIGHT=0
# 必需：白名单资产（逗号分隔，address[:effective]；空白/空集合拒绝启动）
TXHARBOR_DEPOSIT_CONTRACTS=0x1111111111111111111111111111111111111111
# 必需：受监控地址（同上语法；空白/空集合拒绝启动，绝不全地址监控）
TXHARBOR_DEPOSIT_WATCH_ADDRESSES=0xaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa
# 可选：每批最大块数（默认 500；调参不改变历史语义）
TXHARBOR_DEPOSIT_BATCH_BLOCKS=500
# 复用：TXHARBOR_INDEX_POLL_INTERVAL / TXHARBOR_INDEX_RETRY_INITIAL / TXHARBOR_INDEX_RETRY_MAX
# 003 侧：TXHARBOR_LOG_START_HEIGHT / TXHARBOR_LOG_CONTRACTS（004 重算其 config_hash 做上游对齐校验）
```

`:effective` 后缀缺省等于全局起点；大小写/顺序/重复差异不视为配置变化；
新增或删除条目、修改任一高度或起点必须判为变化（比较对象是行内 `start_block` + `config_hash`，
不是 `next_block`）。

## 门禁与残余风险（诚实声明）

- **T000-P 保持 open**：004 自身零 RPC，但生产就绪依赖上游 003 的 E1（provider 附录）；
  在 003 E1 关闭前，004 不得标为生产可用。本地验证范围 = Anvil + DB 播种。
- **偶发本地测试失败原因未知**：保留记录、不标记已修复；时序敏感测试按固定批次执行，
  每批次恰好 5 次并记录全部结果，任一次失败则该批次不通过，不追加运行凑成功；
  修复或明确诊断后的重跑另记批次并保留原证据；未解释失败持续作为未解决事项，
  后续成功批次不能自动将其关闭；重跑须记录具体修复或诊断依据及与原失败的关系，
  无法取得新证据时停止无目的重跑并报告待诊断问题；
  实现阶段 `-race` 双连接测试同样按批次记录，不得以"本地偶发"豁免门禁。
- **003 实现验收证据待核验**：R10 待核验项（Coordinator 第三循环注册点、serve 接线、迁移顺序、
  NUMERIC 映射、授权事务载体形状）是实现前置条件；实现开始前逐项确认，阻塞项显式报告。
- **授权转换审计**：每次授权以 DB history 行为准（`transition_total` 计数为索引）；D11 逐项真库断言；
  覆盖修复必须附带回放区间 `N_u` 证明，仅记新哈希而无覆盖证明的实现视为违反 FR-07。
