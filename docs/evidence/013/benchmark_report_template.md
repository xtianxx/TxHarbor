# 013 对照基准报告模板（V-BENCH / SC-11）

> 本文件是 T077 的报告模板：定义 `docs/evidence/013/benchmark_report.md` 必须包含的字段与口径。
> 实际报告由 `internal/perf` 基准 harness（`make test-perf`）在真实 A/B 运行后自动生成；
> **未测数值一律标「待测/待裁决」，0 次表述为「已达标」**（SC-11；verification.md §5）。
> Kafka/Redis 范围调整须按 PD-3 另行提交用户决定，报告不自动删减或扩大范围。

## 元数据（必填）

| 字段 | 说明 |
|---|---|
| commit | 证据绑定的 commit（`git rev-parse HEAD`） |
| Go 版本 | `go version` |
| 生成时间 | RFC3339 |
| 原始证据目录 | 逐请求样本、逐状态导出、指标导出的存放路径（不入库） |
| 运行次数 | 每路径重复轮数 |

## 1. 方法（同负载同故障对照）

- **路径 A（PG-only）**：PostgreSQL + Anvil；013 接线关闭；事件在 outbox 累积但不投递（仅对照实验）。
- **路径 B（全栈）**：PostgreSQL + Anvil + Redis + Kafka；缓存/限流/容量门禁/发布器/消费者全开。
- **受控变量**：同一主机；同一 PG 规格；同一 Anvil；同一数据集与初始状态；同一负载生成器（固定速率阶梯与突发）；同一故障时间线。
- **负载 profile（固定）**：预热时长；每状态窗口；查询速率阶梯；突发（数量/时刻）；创建速率；存款速率。
- **故障时间线（固定）**：normal → redis_down（停 Redis）→ kafka_down（挂起 Kafka，保留位点）→ dual → recovery（恢复并测量追赶）。
- **测量口径**：客户端逐请求采样为准（原始样本存证）；吞吐=完成数/窗口（排除预热）；百分位=线性插值；
  outbox 待发/最老等待/尝试总数/消费缺口直读 PG；Kafka 高水位与消费组位点直读 broker；
  发布失败/隔离以发布器与消费者的结构化记录计数（其命令无 metrics 端点）；
  RPC 以链侧存款操作耗时为代理（服务端按调用类直方图不在本 feature 指标集内）；
  追赶时间=恢复时刻到消费缺口归零；排空时间=恢复到 outbox 待发与缺口同时归零；
  资源=进程级 CPU/RSS/磁盘 IO/网络/PG 连接池（同进程含负载生成器，为上界）。
- **重复与误差**：每路径重复轮数、逐轮值与极差；单轮内 stddev 见原始样本。

## 2. 环境规格（绑定 commit）

- 主机：CPU 型号/核数、内存、OS/Arch、内核。
- 容器：PG 镜像、Anvil 镜像、Kafka 镜像/topic/分区、Redis 镜像。
- 数据集规模：种子请求、授权池、负载参数。
- 配置输入：路径 B 的 bench 输入键值（**非生产阈值**）。

## 3. 路径 A（PG-only 基线）结果

逐状态（normal/redis_down/kafka_down/dual/recovery）：

| 字段 | 说明 |
|---|---|
| 窗口(s) | 实测窗口时长 |
| 查询 n / RPS / p50 / p95 / p99 / 错误率 | 逐请求采样聚合 |
| 创建 n / p50 / p95 / p99 / 错误率 | 同上 |
| 存款 n | 链上事实计数 |
| Outbox 待发（后）/ 最老等待 / 已发布 / 消费缺口 | 窗口结束时快照 |
| 追赶 / 排空 | 路径 A 无事件通道 → n/a |
| 资源 | CPU(s)/RSS/磁盘/网络/PG 连接/限流/缓存/容量计数 |

## 4. 路径 B（全栈）结果

同 §3 字段；另加：限流拒绝、缓存命中/未命中/回退、容量拒绝、Kafka 高水位与已提交位点。

## 5. A/B 对照

- **5.1 关键指标（跨重复中位数）**：每状态 × 查询 p50/p95/p99、查询错误率、创建 p95、创建错误率，A 值 / B 值 / B−A。
- **5.2 故障期降级行为对比**：redis_down（PD-1 新创建拒绝 vs 路径 A 无依赖）、kafka_down（积压 vs 仅累积）、dual、recovery。
- **5.3 追赶时间（路径 B）**：消费缺口归零、全链路排空；追赶阈值配置项状态（待裁决须显式标注）。

## 6. 资源占用

每状态 A/B 的 CPU(s) 与 RSS(MiB)（跨重复中位数）。

## 7. 重复运行与测量误差

逐轮查询 p95 与极差；单轮 stddev；未重复时的「方差待测」声明。

## 8. 结论与置信限制

- 数据支持的结论（逐条绑定实测数值；不写「已达标」）。
- Kafka/Redis 价值结论（PD-3：只报告、不自动调整范围）。
- 置信限制：单主机/容器化/短窗口/合成负载/同进程负载生成器/客户端延迟口径/故障注入方式差异。

## 9. 未测 / 待裁决

至少列出：生产容量阈值、生产限流速率、追赶 lag 阈值配置项、告警阈值校准、长稳与多主机基准、
生产负载回放、CI 耗时预算（B11 T084）、生产 RPC/公网环境、服务端 RPC 延迟直方图（按调用类）。
